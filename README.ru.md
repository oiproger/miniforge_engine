# Miniforge Engine

**English version:** [README.md](./README.md)

Лёгкий браузерный 3D-движок и студия прототипирования «всё в одном» на базе **LittleJS 1.30.1** (WebGL2 3D), **Rapier3D** (WASM-физика), **React 19 + TypeScript 5.9** и **Tauri v2** (опциональные десктоп-сборки).

Создавался под инди-разработку и геймджемы: моделируйте low-poly ассеты, рисуйте 2D/3D-текстуры, синтезируйте звуки и музыку, собирайте логику нодами (Blueprints), делайте диалоги и катсцены и экспортируйте игры в Web (HTML5, Яндекс Игры, Poki) или Desktop, не покидая редактор.

- **Запустить редактор в браузере:** `https://YOUR_GITHUB_USERNAME.github.io/miniforge-engine/editor/`
- **Полная документация (v2.2):** `https://YOUR_GITHUB_USERNAME.github.io/miniforge-engine/docs/`

## Что внутри

- **Редактор сцен и живые префабы:** 3D-вьюпорт, гизмо, террейн, навигация NavGrid, свет/постпроцессинг и 3D-пипетка выбора объектов прямо со сцены.
- **Event Graph (Blueprints):** визуальное программирование на нодах с типизированными пинами, переменными и кастомными функциями (в дополнение к скриптам на TypeScript).
- **Low-Poly CSG Mesh Builder:** булевы операции (`Union`/`Subtract`), `Extrude`/`Inset`/`Subdivide`/`Mirror X`, быстрая UV-развёртка, неограниченные слои материалов и 3D-кисть 512×512 с экспортом в `.glb`.
- **Model Editor:** импорт 3D-моделей через `assimpjs` WASM, переопределение материалов и нарезка анимаций по таймлайну.
- **2D Paint Editor:** слои, симметрия, бесшовный тайлинг 3×3 и экспорт в PNG.
- **Sound / SFX / Music Synth:** пресеты, 16-шаговый секвенсор, экспорт `.wav` и модификация звука в рантайме (`setSemitones`, `setSpeed`, `setLowpass`).
- **Dialogue & Quest Graph + Keyframe Sequencer:** ветвящиеся диалоги, квесты и многодорожечные катсцены.
- **Система плагинов (v2.2):** создание, редактирование и импорт/экспорт `.mfplugin.json` с расширением редактора и рантайма (в комплекте 4 примера от простого HUD до RPG-инвентаря).
- **Экспорт:** автономный HTML5, адаптеры под Яндекс Игры и Poki, десктоп-сборки через Tauri v2.

## Быстрый старт

Требования: **Node.js 20+** и **pnpm 10+**.

```bash
pnpm install
pnpm dev
```

### Основные команды

```bash
pnpm typecheck      # Проверка типов TypeScript
pnpm build          # Сборка веб-редактора в dist/editor/
pnpm build:site     # Сборка лендинга + документации + редактора в dist/pages/
pnpm test           # Юнит-тесты (Vitest)
pnpm desktop:editor # Десктопная сборка редактора (Tauri v2)
```

## Известные ограничения

- Движок ориентирован на **low-poly / стилизованное 3D** и быстрое прототипирование, а не на тяжёлую AAA-графику.
- Требуется поддержка WebGL2; для слабых мобильных устройств на крупных сценах рекомендуется использовать статический батчинг и дистанцию отсечения.
- Плагины выполняются в лёгком контексте (`new Function`) и рассчитаны на доверенный код автора или проверенного сообщества.
