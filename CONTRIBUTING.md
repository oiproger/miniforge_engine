# Contributing to Miniforge Engine

Contributions, bug reports, UX feedback, and community plugins are very welcome!

## Reporting Bugs
Open a GitHub Issue with:
1. Browser & OS version
2. Minimal steps to reproduce
3. Console error output (if any)

## Submitting Pull Requests
1. Fork the repository and create a branch (`git checkout -b fix/my-change`).
2. Run `pnpm typecheck` and `pnpm test` before pushing.
3. Keep PRs focused on a single feature or fix.

## Sharing Community Plugins
Export your plugin as `.mfplugin.json` via **Plugins → Export** and open a PR or Issue to add it to the community showcase.
