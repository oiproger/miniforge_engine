# Компоненты объекта сцены

Выберите объект в иерархии и откройте Add Component в Inspector. В таблице приведены имена из меню редактора. Идентификаторы компонентов пригодятся при работе с данными сцены и настройке Network Sync.

| Компонент | ID | Для чего применять |
|---|---|---|
| Mesh Renderer | `mesh` | Показывает примитив или импортированную модель glTF. Начните с него, если в сцене нужен видимый предмет. |
| 3D Particle Emitter | `particle` | Создаёт поток частиц, например дым, искры или дождь. |
| 3D Billboard | `billboard` | Поворачивает спрайт к камере. Для анимированного эффекта используйте атлас. |
| 3D Decal | `decal` | Накладывает изображение на поверхность. Подходит для следов, пятен и разметки. |
| Light | `light` | Освещает сцену. Тип источника определяет направление и область воздействия. |
| Volumetric Light | `volumetric` | Делает световой конус видимым в воздухе. |
| Bake & Reflection Zone | `bakeZone` | Задаёт область расчёта статического освещения и отражений. |
| Water Surface | `water` | Рисует анимированную поверхность воды с волнами и пеной. |
| Terrain | `terrain` | Хранит карту высот и слои покрытия для инструментов скульптинга и покраски. |
| Camera | `camera` | Определяет перспективный или ортографический вид игровой сцены. |
| Collider | `collider` | Задаёт форму столкновения. В режиме триггера подходит для зоны подбора или входа в магазин. |
| Physics Body | `body` | Задаёт поведение физического тела. Для падающего предмета совместите динамическое тело и коллайдер. |
| Script | `script` | Подключает TypeScript-скрипт с GameAPI и обработчиками жизненного цикла. |
| Behavior | `behavior` | Добавляет готовый игровой модуль. Список модулей и исходные параметры приведены в разделе «Поведения и события». |
| Event Graph | `eventGraph` | Выполняет визуальную логику объекта. Начните с Event Start и протяните связь исполнения к действию. |
| Audio Source | `audio` | Воспроизводит пространственный или фоновый звук. |
| Animation Player | `animation` | Воспроизводит скелетные клипы glTF или анимацию трансформаций. |
| NavGrid Zone | `navZone` | Задаёт область сетки для поиска пути A*. Соедините раздельные участки переходами Off-Mesh Link. |
| Nav Agent (NPC) | `navAgent` | Перемещает персонажа по построенной навигационной сетке. Подготовьте зону до проверки маршрута. |
| Network Sync | `networkSync` | Реплицирует выбранные поля объекта. Проверьте видимость, трансформацию и нужные свойства на втором клиенте. |
| Legacy Sprite | `sprite` | Рисует простой плоский спрайт в трёхмерной сцене. |
