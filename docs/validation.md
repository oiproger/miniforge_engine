# Проверка MVP 0.1

Проверки выполнены на облачном Linux amd64 с Node.js 24 и системным Chromium 156. Браузерные тесты запускают production-сборку на локальном HTTP-сервере под вложенными путями. WebGL2 в этих тестах использует программный рендерер SwiftShader.

| Проверка | Результат |
| --- | --- |
| TypeScript, ESLint, production build | Успешно |
| Vitest | 19 пройденных тестов в 5 файлах |
| Playwright | 7 пройденных сценариев |
| Сериализация | Пять шаблонов, чтение примера, циклический parent, копирование поддерева и переносимый архив |
| Сценарий редактора | Создание и переименование куба, Transform, Rotate, Script, HUD, Play/Stop, сохранение файла, IndexedDB после перезагрузки и повторное открытие архива |
| Runtime | Callback скрипта на столкновение с преградой, фиксированный шаг Rapier, контакт и raycast, изоляция ошибок lifecycle |
| Coin Rush 3D | Preview и Web Standalone, ввод, подбор монеты, таймер, пауза, RU/EN, результат, рекорд после перезагрузки, пропуск и завершение Mock Ads |
| Площадочные архивы | index.html в корне, скомпилированный модуль, отдельные SDK, запуск с локальным адаптером |
| Desktop | Сборка DEB редактора и игры, запуск в WebKitGTK под Xvfb. В игре проверены старт, движение и подбор монеты. Редактор сохранил проект через системный диалог GTK, содержимое архива успешно прочитано. В Chromium проверена выгрузка исходных проектов Tauri обоих профилей |

## Размер и загрузка Coin Rush 3D

| Профиль | Файлы игры, байт | ZIP, байт | JS gzip, байт |
| --- | ---: | ---: | ---: |
| Web Standalone | 697 398 | 181 008 | 168 714 |
| Яндекс Игры | 698 301 | 181 388 | 169 082 |
| Poki | 697 998 | 181 268 | 168 962 |

Геометрия примера создаётся из примитивов, звук подбора — через Web Audio. Отдельных текстур, аудиофайлов и скачиваемых моделей у примера нет. Основные файлы Web занимают 634 586 байт JavaScript, 62 291 байт JSON, 300 байт HTML и 221 байт CSS. Сборщик проверяет граф зависимостей игры на включение React, Monaco и TypeScript. Rapier поставляется отдельным модулем для проектов с компонентом Body.

В одном прогоне Chromium с локальным сервером отметка готовности игры появилась через **608 мс** при первом открытии и **1391 мс** при повторном. Тест увидел меню через 748 и 1578 мс соответственно. По Resource Timing запрошенные ресурсы передали 697 998 байт с заголовками в первом случае и 0 байт при повторной загрузке из кеша. Документ HTML учитывается отдельно от ресурсных записей. Инициализация локального адаптера заняла 0,3 и 0,0 мс. Повторное открытие всё равно создаёт WebGL-контекст и компилирует шейдеры. Измерения на мобильном GPU, медленной сети и с внешними SDK остаются отдельным этапом.

## Границы версии

- Web-сборка и локальные сценарии адаптеров проверены. Проверка реальной рекламы, авторизации игрока, облачного сохранения Яндекса и модерации требует кабинетов разработчика.
- Установщики Linux собраны для amd64 с системным WebKitGTK 4.1. Для Windows подготовлены конфигурация и GitHub Actions runner. Сборка и запуск Windows в этой среде не проверены.
- Базовый контроллер ходит и прыгает по плоской арене. Твёрдые преграды контроллера используют осевые габариты. Так работала версия 0.1. В текущей версии контроллер Rapier поддерживает ступени, склоны и сеточные коллайдеры.
- Модель поддерживает вложенные сцены объектов, несколько игровых сцен и переиспользуемые префабы. Экземпляр префаба — самостоятельная копия. spawnPrefab создаёт игровое поддерево с компонентами, физикой и поведением. Горячая замена скриптов во время игры и npm-импорты в игровых модулях отсутствуют.
- Библиотека группирует ассеты по типу. Пользовательские папки, автоматическое перекодирование текстур, потоковая подгрузка сцен, skybox и лидерборды в эту версию не вошли. glTF импортируется со вложенными данными или при совместном выборе буферов и изображений. Для переноса модели одним файлом подходит GLB.
- У HUD есть проценты позиции, выравнивание, размер, видимость и порядок наложения. Элементы группируются по экранам, а кнопки управляют переходами. Правила в Inspector связывают события, условия и действия.

Архив исходников также проверен после распаковки в чистый каталог. Установка по frozen lockfile, typecheck, 19 модульных тестов и production-сборка редактора завершились успешно.
