# Сборки и SDK площадок

В редакторе выберите Web, Yandex или Poki. Экспорт создаёт ZIP с index.html в корне. Архив проекта .miniforge сохраняет исходные сцены и ассеты, а ZIP игры содержит готовый runtime и скомпилированные скрипты. В терминале выполните `pnpm export:demo` для сборки примера. Для своего проекта используйте `pnpm prepare:runtime`, затем `pnpm exec tsx packages/exporter/cli.ts ./game.miniforge poki ./out`. В out/poki будут статические файлы для размещения по HTTP(S). Файл out/poki-report.json содержит размеры до и после сжатия, список ресурсов и верхнюю оценку начальной загрузки. Итоговый сетевой трафик зависит от заголовков сжатия и кеширования хостинга.

### Web и Preview

Web работает автономно на статическом хостинге без CDN. Браузер проверяет MIME-типы ES-модулей, поэтому для локальной проверки раздавайте каталог через HTTP. Preview исполняет скрипты в iframe с отдельным непрозрачным origin и ограничивающей сетевые запросы CSP. Для каждого проекта редактор хранит ограниченную копию игрового прогресса отдельно от данных редактора. Mock показывает диалог с выбором Complete ad или Skip. В любой платформенной сборке параметр `?mock=1` включает тот же локальный тестовый режим. Без параметра недоступный SDK отключает рекламу и допускает локальные сохранения.

### Яндекс Игры

Архив yandex.zip предназначен для загрузки в черновик игры. Адаптер загружает /sdk.js с домена площадки, вызывает YaGames.init(), получает язык из environment.i18n.lang и уведомляет LoadingAPI.ready() после подготовки игры. GameplayAPI получает переходы start/stop. Fullscreen и rewarded используют adv с обработчиками закрытия и ошибки. Начисление награды разрешает только событие onRewarded. Player API при доступности дублирует локальную запись в облако. Проверьте язык, готовность загрузки, остановку и восстановление звука и игрового процесса, закрытую без награды рекламу, получение награды и восстановление облачного сохранения в тестовом запуске консоли разработчика. [Документация Яндекс Игр](https://yandex.com/dev/games/doc/en/sdk/sdk-about)

### Poki

Отдельный архив poki.zip содержит адаптер Poki. Он загружает SDK v2, выполняет init() и gameLoadingFinished(), сообщает gameplayStart() и gameplayStop() только при переходах состояния и запрашивает commercialBreak() и rewardedBreak() по игровым событиям. Положительный результат rewardedBreak() разрешает начисление награды. Хранилище прогресса локальное. Протестируйте в Poki Inspector старт, переход меню → игра, паузу, конец раунда, блокировку SDK и ответы рекламы. [Официальная документация](https://sdk.poki.com/general) · [Poki Inspector](https://inspector.poki.dev/)

Валидация адаптеров в репозитории использует тестовые объекты с интерфейсами SDK. Реальные рекламные показы и модерацию подтверждает проверка на площадках.
