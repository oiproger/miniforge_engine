# Key Vault

Выберите **File → New project → Key Vault**, затем **Play**. В «Проходе фонарей» держите W или ↑, чтобы пройти по дорожке от входа и собрать три ключа. Третья находка открывает ворота. Пройдите через открытые ворота до порога сокровищницы.

Кнопка **Inventory** и клавиша E отправляют одно действие Interact и открывают инвентарь. Из него можно попасть в **Lantern shop**, обменять печать на фонарь и вернуться через **Back**. У игрока две печати. Количество фонарей и остаток печатей отображаются сразу и сохраняются при переходе в следующую сцену в рамках игры.

Откройте объект **Passage rules** в иерархии. Событие `scene.start` создаёт три экземпляра префаба **Sun Key** у меток **Key marker**. На `coin.collected` правило с тегом `brass-key` увеличивает переменную `keys`. Следующее правило проверяет её и запускает клип **Open** у **Vault gate**. Событие `animation.finished` от ворот снимает коллайдер и включает триггер **Treasury threshold**. Когда игрок входит в этот объём, событие `trigger.enter` переключает сцену. Ту же структуру можно собрать в Inspector. В **Project → UI editor** редактируются обе панели, счётчики и кнопки.

Для самостоятельной веб-сборки из корня проекта:

```sh
pnpm prepare:runtime
pnpm exec tsx packages/exporter/cli.ts 'examples/Key Vault.json' web dist/key-vault
```
