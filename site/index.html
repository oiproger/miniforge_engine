Все ключевые возможности движка

Кроссплатформенный экспорт

Один проект — любые площадки

Единый слой PlatformAdapter и SaveSystem автоматически адаптируют облачные сохранения, рекламу, язык и управление под целевую платформу.

WEB

HTML5 / itch.io

Автономный ZIP-архив без тяжёлых WASM-гигантов. Мгновенный запуск в любом браузере.

WebGL2 · ~1.5 MB
YA

Яндекс.Игры

Встроенный адаптер Yandex SDK: облачные сейвы, язык игрока, rewarded/interstitial реклама, пауза.

Cloud Sync · Ready API
PK

Poki

Поддержка Poki SDK (`gameplayStart`, `commercialBreak`, `rewardedBreak`) и авто-мут аудио.

Poki SDK Profile
PC

Desktop (Tauri)

Нативные бинарники Windows, macOS и Linux с прямым сохранением на диск по Ctrl+S.

Win · macOS · Linux
MOB

Mobile Touch

Настраиваемые виртуальные джойстики, кнопки и двусторонняя эмуляция мышь ↔ тач как в Godot.

Multi-Touch · api.touch
